What the app does

Ask Grok about this

The Industrial Gearbox Data app (Ram-Gear's QC Form app) replaces the paper quality-control forms for gearbox repairs. For each customer and job (work order) you fill in the Teardown Evaluation and Assembly Verification for every gearbox, add photos where they belong, and finalize each form into a locked PDF report. The app also builds a Parts Summary (parts to order), exports a combined PDF and a job zip, and keeps every tablet in step through the company cloud. It works offline; changes are sent when the connection is back.

1Before you start

Ask Grok about this

You need:

  • The app address: https://ram-gear.github.io/ramgear-app/
  • A tablet or Windows PC with Chrome, Edge or Firefox. Chrome or Edge is recommended because the app can be installed like a normal program.
  • Internet for the first setup. After that the app also works offline.
  • Your username and password or PIN. Your Admin gives you these in person; there is no self sign-up.
  • A Tablet ID for the device, which is simply its name, for example Shop Tablet 2 or Office PC. It is printed on every job and finalized form.
  • First tablet only: the one-time setup code. You get it from the Ram-Gear Admin; it is not written anywhere in the app or this page.

2Set up the first tablet (Admin)

Ask Grok about this

Do this once, on the Admin's tablet, which is usually the one that already has the shop's jobs on it.

  1. Open https://ram-gear.github.io/ramgear-app/ in Chrome or Edge.
  2. Install the app. Chrome: click the install icon at the right end of the address bar, then Install. Edge: menu … › Apps › Install this site as an app.
  3. Sign in with your Admin username and password/PIN. On a brand-new device, fill in Create the first Admin account instead: your name, the Tablet ID and a password/PIN.
  4. Tap Admin in the top bar.
  5. Find the Cloud sync box and tap Connect this tablet to the cloud.
  6. Type the setup code you received from the Ram-Gear Admin.
  7. Type your own password or PIN and tap Connect.
  8. Wait until the Cloud sync box shows On. Everything on this tablet (users, customers, jobs, photos, final PDFs) is now uploaded.
  9. Under Users, tap + New user for each person who needs access. Give them their username and password/PIN in person.
The setup code works only once. After the first tablet is connected, all other devices sign in with a normal username and password/PIN.

3Add more tablets or a Windows PC

Ask Grok about this

  1. Open https://ram-gear.github.io/ramgear-app/ in Chrome or Edge. If you use Firefox, first do section 4.
  2. Install the app (Chrome: install icon in the address bar; Edge: … › Apps › Install this site as an app).

  4. Type your username.
  5. Type your password or PIN.
  6. Type a Tablet ID for this device, for example Shop Tablet 3 or Office PC.
  7. Tap Connect and wait while the company data downloads.

Other people can sign in on this device with their own username and PIN. Accounts are the same on every tablet.

4Firefox settings

Ask Grok about this

Only needed on devices that use Firefox. Without these settings, Firefox may delete the app's data every time it closes, and the app then asks for setup again.

  1. Open the Firefox menu ☰ › Settings.
  2. Click Privacy & Security.
  3. Under Cookies and Site Data, click Manage Exceptions….
  4. Type https://ram-gear.github.io in the address box.
  5. Click Allow. Use Allow, not "Allow for Session".
  6. Click Save Changes.
  7. Scroll to History and make sure Firefox will is set to Remember history, not "Never remember history". Don't use a Private Window for the app.
  8. Click General, scroll to Files and Applications › Downloads, and select Always ask you where to save files. Firefox then asks where to put backups and PDFs.
  9. Close Firefox, open it again and open the app. You should see the sign-in screen, not setup.

5Daily use & sync status

Ask Grok about this

  1. Open the app from its icon.
  2. Sign in with your username and password/PIN.
  3. Check the cloud status in the top bar (see the table below).
  4. Open the customer, the job and then the form you work on.
  5. If the form says In use on …, someone else has it open. Wait, or ask them to leave the form, then tap Check again.
  6. When you are done with a form, leave it with the back button so others can edit it.
  7. Tap Log out when you walk away from the device. It also locks by itself after a few minutes without use.

6Jobs, gearboxes & reduction type

Ask Grok about this

A job can hold one or more gearboxes. Each gearbox has its own reduction type (Single, Double or Triple), its own manufacturer, model and serial number, and its own Teardown Evaluation and Assembly Verification. The forms follow the type: ratios for each stage, the shafts (Single: input and output; Double: plus an intermediate shaft; Triple: plus two intermediate shafts), gears and pinions per stage, bearings and shims per shaft, and backlash for each gear mesh.

Planetary gearboxes (Rev 1.6) are a fourth type. When you pick Planetary, also pick the number of planetary stages (1 to 4); both are confirmed and locked together. The planetary forms have a section per stage: tooth counts and number of planets, the stage ratio (calculated as 1 + Z ring / Z sun from the tooth counts, plus the measured ratio), sun-planet and planet-ring backlash, sun float, carrier endplay and thrust washer thickness, and the sun gear, each planet (pin fit, needle rollers, thrust washers), ring gear, planet carrier and carrier bearing, and the coupling to the next stage. Input and output shafts, bearings, seals, housing, lubrication and the shim records (with Replace / Reuse) follow. In the planet table, fill in one row per planet: rows above the number of planets you entered are not required. Teardown parts keep Reuse / Repair / Replace, and the failure-mode and root-cause sections are the same as for the other types.

Customer cards: View card and Find in card file (Rev 1.8)

Ask Grok about this

Every customer has a card in the company cloud, shared with the Cardfile app: the customer name (up to 39 characters) and a contact block (contact, phone, email, address, notes). It updates by itself whenever the customer is saved on any tablet.

  • View card (customer screen) shows the card. Online it comes from the cloud, including any notes added in Cardfile; offline the tablet builds it from the customer details.
  • Find in card file (top of + New customer): type 2 or more letters of the company, contact, phone or email. Tap a card to fill in the form, check or edit the details, then tap Create customer; the card is linked to the new customer. Cards already linked to a customer are greyed out. Needs internet and the cloud sign-in; offline it shows Card lookup needs internet.
  • If the connection drops after you picked a card, save anyway: the card is linked at the next sync. If another tablet linked the same card first, you get a warning and the new customer gets its own card.

Try it: phone numbers

A (made-up) customer gave the phone number +1 (555) 010-0188. Type it the way the app shows it on the customer and the card.

Start a job

  1. Open the customer and tap + New job.
  2. Type the work order number. Fill in manufacturer, model and serial number of gearbox 1 if you have them.
  3. Under Gearbox type, tap Single, Double, Triple (reduction type) or Planetary. For Planetary, also tap the number of planetary stages (1–4). The app won't create the job without it.
  4. Tap Create job.
  5. Check the type in the confirmation and tap Confirm … & lock. Tap Back to pick another one. The type is now locked 🔒.

Try it: pick the gearbox type

Practice job WO 00-0000 (sample data): the gearbox is a planetary gearbox with 2 planetary stages. Pick what you would tap on + New job.

Add another gearbox to the job

  1. Open the job folder and tap + Add gearbox (below the gearbox cards).
  2. Fill in the gearbox details, pick its type (and the planetary stages, for Planetary) and tap Add gearbox.
  3. Confirm the type. The new card shows Gearbox 2 of 2 with its own forms. Teardown Evaluation is listed before Assembly Verification.

You can add gearboxes until every form of the job is finalized. Labels like Gearbox 1 of 2 (with type and serial number) appear on the forms, on every page of the PDFs, in file names (_GB1, _GB2) and in the zip, which has one folder per gearbox. The combined PDF is grouped per gearbox, each group starting with a cover page. Jobs created before Rev 1.5 count as one Double-reduction gearbox; nothing in them changed.

Change the type or remove a gearbox (Admin)

  1. In the gearbox card, tap Change type or Remove gearbox.
  2. For a type change, pick the new type (for Planetary also the number of stages; changing only the number of planetary stages is a type change too) and confirm it. This works only while none of that gearbox's forms has been finalized. After that, the final PDFs are the record, so remove the gearbox and add it again if the type was wrong.
  3. Approve with the Admin password/PIN. The change is written to the audit log and synced to all tablets.

A removed gearbox disappears from the job, the counts and the exports. Its saved final PDFs are kept, listed as “Removed gearbox”.

Shim records: Replace or Reuse

Ask Grok about this

Every row of the shim records (As-found shim record in the Teardown Evaluation, Bearing shim record in the Assembly Verification) has a Shim pack: Replace / Reuse choice. Tap one; tapping the other switches it. It is required to finalize, like the other values in the row. If the row does not apply, tap N/A for the whole row. The choice is printed in the shim table of the final and combined PDFs. Forms started before Rev 1.5.2 show it blank until you pick one.

Photos in the report

Ask Grok about this

Oil photos: open C. Oil condition → Section photos (not L. Teardown photos) so they print under “Photos - C. Oil condition”. From Rev 1.7.1 the gallery button keeps that section even on tablets. If an older oil picture prints under L, delete it and add it again under C, then re-finalize.

Job photos (job folder or the Job photos block on a form) print at the end of every form PDF. From Rev 1.7.2 every readable job photo is included; the report no longer leaves blank pages for pictures that failed to load. Re-finalize to refresh an older final PDF.

Take or pick photos where they belong: every section has Section photos, and every part row has its own Photos. The thumbnails show right there in that section, with their caption; tap one to see it full size (deleting needs Admin approval, as before). In the PDF report (final, draft and combined), each section's photos print right after that section: a small grid, 3 per row, with the caption under each photo and a note that the full-size photos are in the app and the job export. A part's photos print with its section and show the part name.

The last section of every Teardown Evaluation (all gearbox types) is L. Teardown photos for general teardown photos. Tap 📷 Take photo or 🖼 Choose from gallery (several at once) and give each a short caption: type it, or pick a suggestion such as As received, Disassembled or a component name. The Assembly Verification has Additional photos at the end for the same purpose. Both are optional; they are not needed to finalize. Photos whose section no longer exists (for example after a gearbox type change) are shown and printed there. Job photos print at the end of each form. In the job zip, photos are in each gearbox's Photos/ folder, full size, in report order, with the section at the start of the file name (e.g. 03_Teardown-C_Oil-condition_Sample-jar.jpg). Photos and captions sync to the other tablets.

Parts Summary (parts to order)

Ask Grok about this

Each job folder has a Parts Summary card. Tap Parts Summary to see, for every gearbox (all types, including Planetary), what has to be ordered. It is built automatically from the Teardown Evaluation and updates as you fill the forms in:

  • Parts to replace: every component marked Replace, and planet gears marked Replace, with location, quantity, part number (bearing cone / cup P/N, seal P/N) and the findings as failure mode / notes. Components marked Repair are listed separately under Parts to repair.
  • Shim packs to replace: shim rows marked Replace. For a shaft that has a choice in the Assembly Verification, that choice counts; otherwise the Teardown Evaluation's as-found choice.
  • Totals by type, e.g. Tapered roller bearing – 4, Oil seal – 2, Gasket – 1, Shim pack – 3, and a Job roll-up with the totals across all gearboxes of the job.

Quantity: each component has an optional Qty needed field (for the Parts Summary only, not printed on the form). Leave it empty to use the default shown in the field: 1, 2 for a shaft's bearing pair, or per planet for planet bearings, pins and thrust washers (enter the number of planets; if it is empty, 3 is assumed and noted). Bearings also have an optional Bearing type (pick a suggestion such as Spherical roller bearing); bearings with cone / cup fields default to Tapered roller bearing. For Other component rows, a name such as “Cover gasket” or “O-ring” puts it in the right group.

Until a gearbox's Teardown Evaluation is finalized, its summary is marked DRAFT (quantities may still change); after that it is marked FINAL. The Parts Summary page is added at the end of the final Teardown PDF, after the teardown sections in the combined job PDF (with the job roll-up last), and as its own PDF with Download Parts Summary. The job zip also contains …_Parts-Summary.pdf and …_Parts-Summary.csv (opens in Excel). Each page shows the Ram-Gear header, the job, customer, work order, gearbox, Tablet ID and app revision.

7Backups & restore

Ask Grok about this

The cloud keeps a copy of everything, but a backup file is still your safety net.

Make a backup

  1. Tap Backup in the top bar of the home screen, or go to Admin › Backup all data.
  2. In Chrome or Edge, tap Save as… and choose a folder, for example a USB drive or a OneDrive folder. Otherwise, tap Download (the file goes to the Downloads folder; Firefox asks where if you did step 8 of section 4) or Share on a tablet (Drive, Files, e-mail).
  3. Keep the suggested file name. It looks like ramgear-backup-2026-09-30-0858-Rev1.5-ShopTablet1.json: date, time (24 h), app revision and Tablet ID, so the files sort in date order.
  4. Keep a copy somewhere other than the tablet.

Restore a backup

Careful when cloud sync is on: restored jobs are sent to the cloud and can replace newer changes made on other tablets for the same jobs. Finalized forms stay locked. Restore only when data is really lost, on one device, after talking to the Admin. If a device only lost its own copy, use section 8 instead.
  1. Sign in as an Admin and tap Admin.
  2. Tap Restore from backup.
  3. Choose the backup file. Older names like ramgear-backup-2026-09-29.json also work.
  4. Read the summary (customers, jobs, photos, PDFs) and tap Restore.
  5. Approve with the Admin password/PIN.
  6. Wait until the cloud status shows ☁ Synced.

8If browser data is cleared

Ask Grok about this

The app keeps its data in the browser. If that data is deleted (by "clear browsing data", a privacy setting, or a Private/Incognito window), the app opens with Create the first Admin account as if it were new. With cloud sync, everything that was synced is still safe in the cloud.

  1. Do not create a new admin account.
  2. Tap Connect to company cloud.
  3. Type your username and password/PIN.
  4. Type the same Tablet ID the device had before.
  5. Tap Connect and wait for the download.
  6. Fix the browser setting so it doesn't happen again: in Firefox follow section 4. In Chrome or Edge, don't clear site data on exit and don't use Incognito/InPrivate.
Changes that were still waiting (the device was offline) when the data was cleared are lost. Without cloud sync, restore the newest backup file instead (section 7).

If the cloud lost its data ("Cloud empty – re-upload needed")

This is the opposite case: the data on the device is fine, but the company cloud was emptied or lost your account. The app then stops syncing and deletes nothing on the device. The top bar shows ☁ Cloud empty – re-upload needed or ☁ Cloud account missing.

  1. Make a backup first (section 7). It's a safety net.
  2. On the Admin's device, tap Admin.
  3. In the Cloud sync card, tap Re-upload all data from this device.
  4. If the cloud is empty, type the new one-time setup code from the Ram-Gear Admin.
  5. Type your password/PIN and tap Re-upload.
  6. Wait until the top bar shows ☁ Synced.
  7. On every other device, log out and sign in again while online.

9The screens, one by one

Ask Grok about this

Sign-in

Type your username and password/PIN and tap Sign in. After 5 wrong tries the device waits a short time before you can try again. The links at the bottom open this guide (Help & setup guide) and Ask Grok. A brand-new device shows Create the first Admin account instead (see sections 2 and 3).

Top bar

Shows the company name, the app revision (tap it for details), the cloud status (section 5), your name and role, Log out, Help and Ask Grok. Some screens add buttons here, for example Backup on the home screen.

Home – customers

Lists all customers with a search box. Tap a customer to open it. Technicians and Admins see + New customer. A backup reminder appears here when one is due.

Customer

The customer's details and their jobs. Buttons: View card (the shared customer card, see Customer cards), Edit, + New job and, for Admins, Delete.

Job folder

One card per gearbox with its type and its two forms (Teardown Evaluation, Assembly Verification) and their status: not started, draft, or ✓ completed. Below: Job photos, Saved documents (final PDFs), the Parts Summary card, + Add gearbox, and the exports Combined PDF and Export zip.

Forms

The form opens in sections (A, B, C …). Everything saves automatically as you type, also offline. Required items are marked; tap N/A for an item that doesn't apply. While you have a form open it is checked out to your tablet, so other devices see it as In use and read-only. Leave with the back button when you are done.

Photos

Every section has Section photos and every part row has Photos; the job has Job photos. Tap 📷 Take photo or 🖼 Choose from gallery and give each photo a short caption. Photos print in the PDF under the section where you added them (see Photos in the report).

Finalize

Tap Finalize at the end of the form. If required items are missing, the app lists them and Go to first takes you there. When all are complete, tap Finalize & save PDF: the form is locked, the Tablet ID and time are stamped, and the final PDF is saved in the job's Saved documents. Only an Admin can Reopen a completed form (with approval); finalizing again makes a new revision.

Parts Summary

Parts to replace or repair and shim packs, per gearbox and as a job roll-up, built from the forms. See Parts Summary.

Backup / restore

Backup saves everything on the device to one file; Admins can restore it. See section 7.

Cloud sync

All tablets share one company cloud. The top bar shows the status; Admins see details and Sync now under Admin › Cloud sync. See section 5.

Admin › Users

Admins add users (+ New user), reset passwords/PINs, disable or enable accounts, and set each user's QC role, Card file role and Change Gear role (see User roles). Admin also holds the Tablet ID, auto-lock time, backup reminder and the audit log.

Ask Grok

Ask Grok about this

Ask Grok (top bar and sign-in screen) opens grok.com in a new tab with a fixed question asking Grok to read this guide and give you pointers. It sends no customer, job or user information, only that question. It needs an internet connection; the app itself keeps working offline.

10Common tasks, step by step

Ask Grok about this

Record a new gearbox repair

  1. Home: open the customer, or tap + New customer (use Find in card file to fill in the details).
  2. Tap + New job, type the work order number, pick the gearbox type and tap Create job, then confirm the type.
  3. In the job folder, open the Teardown Evaluation, fill it in and add photos as you go.
  4. Tap Finalize, fix any missing items, then Finalize & save PDF.
  5. Check the Parts Summary for what to order.
  6. After the rebuild, fill in and finalize the Assembly Verification the same way.

Send the report to a customer

  1. Open the job folder.
  2. Tap Combined PDF (all final forms) or Export zip (PDFs and photos).
  3. Tap Share, Save as… or Download and send the file as usual.

Correct a completed form

  1. Ask an Admin to open the form and tap Reopen (Admin approval).
  2. Make the change.
  3. Finalize again; the new PDF gets the next revision number and the old one stays in Saved documents.

Add a user or change a role (Admin)

  1. Tap Admin, then under Users tap + New user or Edit.
  2. Fill in the name and username and pick the QC, Card file and Change Gear roles.
  3. For a new user, set a password/PIN and tell them in person.

Set up another tablet

Follow section 3.

12Setting up for another shop

Ask Grok about this

This address, https://ram-gear.github.io/ramgear-app/, uses Ram-Gear's database and needs a Ram-Gear account. Another shop that wants the app with its own data makes its own copy:

  1. Fork the app on GitHub and turn on GitHub Pages. This gives the shop its own web address.
  2. Create a Supabase project for the shop and run the included SQL setup, which creates the tables, security rules and a private file bucket.
  3. Turn off public sign-ups and install the included user-admin function with the shop's own setup code.
  4. Put the project URL and publishable key in the one config file, js/config.js.
  5. Change the logo, name, address, background photo and colours.
  6. Create the first Admin, connect it to the cloud and name the tablets, as in sections 2 and 3.

Full instructions: docs/SETUP-FOR-OTHER-SHOPS.md on GitHub.
